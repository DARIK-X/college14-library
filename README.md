# Электронная библиотека колледжа №14

Самостоятельный Laravel 12 проект в оформлении предоставленного сайта: сине-белая палитра, плавные карточки, большой первый экран. Исходный архив содержит React сайт Жетісайского районного отдела образования, поэтому его название и контактные данные здесь не использованы. Фоновое оформление выполнено без фотографий других учреждений.

## Установка

Нужны PHP 8.2+, Composer, расширения PHP SQLite, Fileinfo, Mbstring и OpenSSL. Корень веб-сервера должен указывать на `public/`.

```bash
composer install
cp .env.example .env
touch database/database.sqlite
php artisan key:generate
php artisan migrate
php artisan library:create-admin admin@example.kz "Администратор"
php artisan serve
```

Сохраните случайный пароль из команды. Вход: `/admin/login`. Поменяйте `APP_URL` и `APP_DEBUG=false` в `.env` перед размещением на сервере. Веб-серверу нужны права на запись в `storage/` и `bootstrap/cache/`. Для продакшена используйте HTTPS и настроенный веб-сервер. Локальные файлы PDF и обложек сохраняются в `storage/app/private`, выдаются только через контроллер; книги доступны без входа. Администратор может добавить, изменить и удалить книгу, PDF и обложку. Доступны PDF до 50 МБ и обложки JPG/PNG/WebP до 5 МБ. Публичная регистрация выключена.

Сайт доступен на казахском, русском и английском. Переключатель сохраняет язык в сессии; интерфейс админки на русском. Книги и их метаданные администратор добавляет самостоятельно; демонстрационных или чужих книг нет. Заголовки и описания страниц содержат запросы «14 колледж» и «14 колледж кітапхана» без обещания позиции в поиске. Отправьте сайт на индексацию после публикации. Кнопки в подвале ведут на KITAP.kz и KazNEB.kz, ссылка возврата — на https://kolledj14.edu.kz/.

Важно: если преподавателям нужны разные учётные записи, текущая версия позволяет создать несколько администраторов командой выше; каждый из них имеет полный доступ к книгам.
